# Keamanan PindaiLoker

## Aturan utama

- Jangan pernah menyimpan password, token, API key, service-role key, atau data rahasia di GitHub.
- Semua secret harus disimpan melalui pengaturan environment layanan terkait.
- Resume dan dokumen pengguna harus berada dalam penyimpanan privat.
- Setiap pengguna hanya boleh membaca dan mengubah data miliknya sendiri.
- Panel admin hanya dapat digunakan oleh akun dengan peran admin.
- Aktivitas penting admin perlu dicatat untuk pemeriksaan.
- Pengguna harus dapat menghapus resume, riwayat lamaran, dan akun mereka.

## Jika menemukan masalah keamanan

Jangan menuliskan data pribadi atau secret di issue publik. Laporkan kepada pemilik proyek melalui saluran privat.
